## Upgrade Guide

Follow these steps to upgrade Bryce Arce to the latest version.

<Steps>
  <Step title="Backup Your Data" icon="database">
    Export all documents via the dashboard at `https://dashboard.example.com/export`.
  </Step>
  <Step title="Update Package" icon="download">
    <CodeGroup tabs="npm,yarn">
````bash
npm install bryce-arce@latest
````
````bash
yarn add bryce-arce@latest
````
    </CodeGroup>
  </Step>
  <Step title="Reconfigure" icon="settings">
    Update your `{API_KEY}` in the config file:
````javascript
const config = {
  apiKey: 'YOUR_API_KEY',
  baseUrl: 'https://api.example.com'
};
````
  </Step>
  <Step title="Restart" icon="play">
    Run `npm start` or restart your server.
  </Step>
</Steps>
